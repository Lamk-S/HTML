## 🎯 Objetivo
Mantener un registro ordenado, progresivo y con buenas prácticas de todo lo aprendido en HTML. El enfoque principal es **estructura y semántica correcta**, accesibilidad básica y preparación para CSS/JS.

No es solo teoría: cada concepto tiene su archivo de práctica y se valida en 2 proyectos completos.
